# Logical Expressions Evaluator

A Python discrete mathematics exercise that evaluates Boolean expressions for user-supplied truth values. It walks a limited set of Python AST nodes to resolve variables, negation, conjunction, and disjunction. [Evaluator](project1%2CREDUX.py)

## Run locally

Run the exercise with Python 3 from the repository root:

    python "project1,REDUX.py"

Enter one to five variables and their true or false values. For three
variables, try the expression `(a and not b) or c`. The assignment's
shorthand `nb` also means `not b`.
